前言

「そうだ」有兩個用法，一為「樣態助動詞」，一為「傳聞助動詞」，兩者意思不同，動詞變化也不同，初學者需注意用法。本篇要看的是「傳聞助動詞」。

傳聞助動詞「そうだ」

傳聞助動詞「そうだ」：
說話者轉述聽來的資訊，譯為「聽說」。

接續用法

【肯定接續】

【否定接續】

動詞

  1. 明日（あした）、雨（あめ）が降（ふ）るそうだ。
    聽說明天會下雨。
  2. 明日（あした）は山田（やまだ）さんが来（く）るそうだ。
    聽說明天山田會來。
  3. 加藤（かとう）君（くん）は行（い）かないそうだ。否定
    聽說加藤不去。
  4. 彼（かれ）は来（こ）ないそうだ。否定
    聽說他不來。

形容詞

  1. 先生（せんせい）は忙（いそが）しいそうだ。
    聽說老師很忙。
  2. 高齢（こうれい）者（しゃ）の事故（じこ）では操作（そうさ）ミスが多（おお）いそうだ。
    聽說老人的車禍事故多為駕駛操作失誤。
  3. 彼女（かのじょ）は家族（かぞく）の誰（だれ）よりも背（せ）が高（たか）いそうだ。
    聽說她是家裡最高的女生。
  4. 先生（せんせい）は忙（いそが）しくないそうだ。否定
    聽說老師不忙。

形容動詞

  1. 鈴木（すずき）君（くん）は最近（さいきん）元気（げんき）だそうだ。
    聽說鈴木最近很好。
  2. そのゲームは入手（にゅうしゅ）が困難（こんなん）だそうだ。
    聽說那個遊戲很難入手。
  3. 市場（いちば）が営業（えいぎょう）している時（とき）は、すごく賑（にぎ）やかだそうだ。
    聽說市場在營業時非常地熱鬧。
  4. 賑（にぎ）やかではないそうだ。否定
    聽說不熱鬧。

名詞

  1. その子（こ）は10歳（さい）だそうだ。
    聽說那孩子十歲。
  2. あの人（ひと）は先生（せんせい）だそうだ。
    聽說那個人是老師。
  3. 林（はやし）さんは大学生（だいがくせい）だそうだ。
    聽說林是大學生。
  4. 林（はやし）さんは大学生（だいがくせい）ではないそうだ。否定
    聽說林不是大學生。

注意「樣態」跟「傳聞」的用法

来（き）そうだ（好像會來）樣態
来（く）るそうだ（聽說會來）傳聞

忙（いそが）しそうだ（好像很忙）樣態
忙（いそが）しいそうだ（聽說很忙）傳聞

賑（にぎ）やかそうだ（好像很熱鬧）樣態
賑（にぎ）やかだそうだ（聽說很熱鬧）傳聞

先生（せんせい）だそうだ（聽說是老師）傳聞

簡易記憶：

傳聞助動詞「そうだ」的前面是完整的普通體句子：来（く）る、来（こ）ない、忙（いそが）しい、忙（いそが）しくない、賑（にぎ）やかだ、賑（にぎ）やかではない、先生（せんせい）だ、先生（せんせい）ではない。

樣態沒有名詞用法，不過否定時可以用：

（錯誤）先生（せんせい）そうだ。→ 名詞沒有樣態用法
（正確）先生（せんせい）ではなさそうだ。→ 名詞否定可以用樣態

另外，「よい」跟「ない」的用法如下：

よい：よさそうだ（樣態）／よいそうだ（傳聞）
ない：なさそうだ（樣態）／ないそうだ（傳聞）

補充

「そうだ」本身不能做過去式（そうだった）
例：

  • 時雨（しぐれ）さんもこの小説（しょうせつ）を読（よ）んだそうだ。
  • 時雨（しぐれ）さんもこの小説（しょうせつ）を読（よ）んだそうだった。
  • 時雨（しぐれ）さんもこの小説（しょうせつ）を読（よ）むそうだった。
