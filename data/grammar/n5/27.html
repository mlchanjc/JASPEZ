N5文法27【助詞篇】「に」解析篇

  1. 表時間（動作發生的時間）
  2. 表歸著點（變換位置的到達點）
  3. 表存在場所（指人事物本身的存在場所）
  4. 表轉換結果（事物或狀態轉變的結果）
  5. 表對象（單向動作所指向的對象）
  6. 表次數（一個期間内包含的次數）
  7. 表目的（移動動詞的目的）

「に」的用法很多，以下為初級範圍內的「に」。

表時間（動作發生的時間）

文法：N＋に＋V
詳細接續：
時間性名詞＋格助詞ニ＋動詞
表示該動作發生的時間。
  1. 私（わたし）は毎日（まいにち）８時（じ）に起（お）きます。
    我毎天八點起床。
  2. 期末（きまつ）試験（しけん）は金曜日（きんようび）に終（お）わります。
    期末考將在星期五結束。
  3. 夏休（なつやす）みに日本（にほん）へ行（い）きました。
    暑假時去了日本。
  4. 私（わたし）は2000年（ねん）に生（う）まれました。
    我出生於2000年。

另外也可以用「ごろ」或「くらい（ぐらい）」表示時間：

  1. ごろ：主要表示某個時間點左右。（不可表示時間長度）
  2. くらい（ぐらい）：主要表示時間長度的左右。（近來演變成也可以表示時間點）

由於「くらい（ぐらい）」屬於表程度上的量，因此用法較廣，可用於表示數量，例如：

  1. 10人（にん）ぐらい（約10人）
  2. 500円（えん）ぐらい（約500日幣）
  3. 10歳（さい）ぐらい（約10歳）

「ごろ」則沒有表示數量的意思，如：10人（にん）ごろ（錯誤）

「ごろ」漢字為「頃」，一般較常使用平假名來書寫。
「くらい」跟「ぐらい」基本上兩者都可以互換。口語上較常使用「ぐらい」，文章則多用「くらい」。

綜合例句：

  • ６時（じ）に起（お）きます。
  • 六點整起床。に要加
  • ６時（じ）ごろ（に）起（お）きます。
  • 六點左右起床。に可加可不加
  • ６時（じ）ぐらいに起（お）きます。
  • 六點左右起床。に要加
  • ６時間（じかん）ぐらい起（お）きています。
  • 起床有約六個小時了。表時間長度，に不加
  • ６時間（じかん）ごろ起（お）きます。 這句是錯的。
  • ６時間（じかん）ごろ起（お）きています。 這句是錯的。

表歸著點（變換位置的到達點）

文法：N（場所）＋に＋V
詳細接續：
場所名詞＋格助詞ニ＋動詞
表示動作到達的位置。
  1. 日本（にほん）に行（い）きます。
    去日本。 → 歸著點在日本
  2. 台北（たいぺい）に着（つ）きました。
    到台北。 → 歸著點在台北
  3. 電車（でんしゃ）に乗（の）ります。
    搭乘電車。 → 歸著點在電車
  4. 黒板（こくばん）に字（じ）を書（か）きました。
    把字寫在黑板上。 → 字的歸著點在黑板
  5. 紙（かみ）に名前（なまえ）を書（か）きました。
    把名字寫在紙上。 → 名字的歸著點在紙上

表存在場所（指人事物本身的存在場所）

文法：N（場所）＋に＋N＋が＋存在動詞
詳細接續：
場所名詞＋格助詞ニ＋名詞＋格助詞ガ＋存在動詞
表示有、在的意思。
場所 に 名詞可以自主移動 が いる
場所 に 名詞無法自主移動 が ある

「いる／ある」是存在動詞，皆表示「有、在」的意思，所謂的存在動詞就是指動詞本身並沒有動作，只是單純描述主詞的存在而已。一般用有沒有生命跡象來判斷要用哪一個，有生命的（如動物）用「いる」，沒有生命的（物體）用「ある」，但由於「鬼」是使用「いる」，「植物」是使用「ある」，不同見解之下容易出錯，最好的分辨辦法就是能自主移動的使用「いる」，無法自主移動的使用「ある」。

  1. 教室（きょうしつ）に学生（がくせい）がいる。
    教室裡有學生。 → 學生＝可以自主移動，用「いる」
  2. 教室（きょうしつ）に机（つくえ）がある。
    教室裡有桌子。 → 桌子＝無法自主移動，用「ある」

除了存在動詞「いる／ある」之外，焦點在於人或物體以靜止狀態存在時也用「に」，例如：座（すわ）る、立（た）つ、置（お）く、住（す）む、泊（と）まる……等。

  1. 台北（たいぺい）に住（す）んでいます。
    住台北。 → 一直在台北
  2. 公園（こうえん）のベンチに座（すわ）っています。
    在公園的長椅上坐著。 → 在長椅上維持坐著的狀態
  3. スマホを机（つくえ）に置（お）きます。
    把手機放在桌子上。 → 放置後，手機一直在桌子上

⚠️ 「ています」是「ている」的丁寧體，表示「動作的狀態」（將於「ている」篇繼續介紹）。

表轉換結果（事物或狀態轉變的結果）

文法：N＋に＋具有轉變效果的動詞（成為、轉、變、改...等等）
詳細接續：
名詞＋格助詞ニ＋具有轉變效果的動詞（成為、轉、變、改...等等）
  1. 部長（ぶちょう）になりました。
    當上部長了。（なる：成為、當上）
  2. 低（てい）血圧（けつあつ）が高（こう）血圧（けつあつ）に変（か）わりました。
    低血壓轉變為高血壓。
  3. 中国（ちゅうごく）語（ご）を日本語（にほんご）に翻訳（ほんやく）してください。
    請將中文翻譯為日文。
  4. バスに乗（の）って、MRTに乗（の）り換（か）えます。
    搭公車轉乘捷運。

表對象（單向動作所指向的對象）

文法：N（對象）＋に＋V
詳細接續：
名詞（對象）＋格助詞ニ＋動詞
表單向作用的對象，即單方面的動作。
  1. 昨日（きのう）、先生（せんせい）に会（あ）いました。
    我昨天去找了老師。
  2. 後輩（こうはい）にお金（かね）を貸（か）しました。
    借錢給學弟。
  3. 猫（ねこ）に餌（えさ）をあげます。
    給貓飼料。
  4. 友達（ともだち）に写真（しゃしん）を見（み）せました。
    我把照片秀給朋友看。

表次數（一個期間内包含的次數）

文法：時間段＋に＋數量詞＋動詞
  1. この薬（くすり）は１日（にち）に３回（かい）、毎食（まいしょく）後（ご）に飲（の）んでください。
    這個藥毎日三次，飯後服用。
  2. 週（しゅう）に１回（かい）読書（どくしょ）会（かい）をやりましょう。
    毎週進行一次讀書會吧！
  3. 月（つき）に１度（ど）旅行（りょこう）します。
    一個月旅行一次。
  4. 年（ねん）に１回（かい）健康（けんこう）診断（しんだん）を受（う）けます。
    一年健康檢查一次。

表目的（移動動詞的目的）

文法：動詞連用形・動作性名詞＋に＋移動動詞
  1. 家（うち）にも遊（あそ）びに来（き）てくださいね。
    也來家裡玩吧！來家裡的目的 → 玩連用形
  2. 映画（えいが）を見（み）に行（い）きます。
    去看電影。去的目的 → 看電影連用形
  3. スーパーへ買（か）い物（もの）に行（い）きます。
    去超市買東西。去超市的目的 → 買東西動作性名詞
  4. 日本（にほん）へ留学（りゅうがく）に行（い）きます。
    去日本留學。去日本的目的 → 留學動作性名詞

「も」、「へ」等助詞會在後面陸續學到。

動作性名詞就是指它是名詞，但是具有動作性質，當加上「する」時可變成動詞
品詞 留學 打掃 念書
名詞 留学 掃除 勉強
動詞 留学する 掃除する 勉強する
